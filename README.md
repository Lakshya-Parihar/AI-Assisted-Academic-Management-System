# AI Assisted Academic Management System

## Overview

The AI Assisted Academic Management System is a full-stack web application designed to simplify and modernize academic administration for educational institutions.

The platform provides dedicated modules for administrators, faculty members, and students while integrating AI-assisted features to improve academic workflow efficiency, analytics, and user experience.

---

# Features

## Admin Module

* Manage students, faculty, and departments
* Course and subject management
* Branch and semester management
* Dashboard analytics and reporting
* Student performance tracking
* Attendance and academic monitoring

## Faculty Module

* Manage courses and assignments
* Upload and review study materials
* Track student attendance, risk Analysis
* Grade assignments and quizzes
* View academic insights and analytics

## Student Module

* View courses and assignments
* Upload assignment submissions
* Check attendance and grades
* Access study materials
* Track academic progress through dashboards

## AI-Assisted Features

* Smart academic insights
* Performance analysis
* AI-assisted dashboards and analytics
* Intelligent data-driven monitoring
* Enhanced academic decision support

# Installation

## Clone Repository

```bash
git clone https://github.com/your-username/ai-assisted-academic-management-system.git
```

## Move Project to Working Directory

For XAMPP users:

```bash
C:/xampp/htdocs/
```

## Install Frontend Dependencies

```bash
npm install
```

## Start Backend Services

Start:

* Apache
* MySQL

using XAMPP Control Panel.

## Import Database

1. Open phpMyAdmin
2. Create a database
3. Import `ams_db.sql`

## Start Frontend

```bash
npm run dev
```
